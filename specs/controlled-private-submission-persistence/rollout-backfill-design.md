## Rollback
Schema added/backend fails or backfill done/service fails: keep writes frozen; keep additive schema/data (do not drop columns/ledger); repair deployment or restore approved backup while frozen if authorized. Admin extension fails/old Admin: keep update gate closed, serve reload-required; never disable CAS to restore UX. Partial deployment: drain incompatible nodes and remain frozen. After accepting controlled writes, do not restore an older snapshot or reset revisions; roll forward or use separately validated recovery under freeze. No destructive automatic rollback.

Backfill is idempotent by null-only target predicate and preserved valid values. Ledger physical schema needed if adopted; public existing rows need no blanket data backfill.
